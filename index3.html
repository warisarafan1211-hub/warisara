การสร้างเว็บไซต์ด้วย AI

เรียนรู้การสร้างเว็บไซต์อย่างง่าย

ขั้นตอนที่ 1 วางแผนเว็บไซต์

กำหนดหัวข้อ จุดประสงค์ กลุ่มเป้าหมาย และเนื้อหาที่ต้องการนำเสนอ รวมถึงเลือกโทนสีของเว็บไซต์

ขั้นตอนที่ 2 ใช้ AI ช่วยเขียนโค้ด

เปิด ChatGPT แล้วพิมพ์คำสั่ง เช่น "ช่วยสร้างเว็บไซต์แนะนำ AI ด้วย HTML และ CSS โทนสีน้ำเงิน มีเมนู 3 หน้า"

ขั้นตอนที่ 3 สร้างเว็บไซต์ใน Notepad

1. เปิดโปรแกรม Notepad
2. คัดลอกโค้ด HTML จาก AI
3. วางโค้ดลงใน Notepad
4. เลือก File > Save As
5. ตั้งชื่อไฟล์ index1.html
6. เลือก Save as type: All Files
7. เลือก Encoding: UTF-8
8. กด Save

ขั้นตอนที่ 4 การใส่รูปภาพ

นำรูปภาพชื่อ banner.png มาเก็บในโฟลเดอร์เดียวกับไฟล์ HTML แล้วใช้คำสั่งแสดงรูปภาพดังนี้ 

<img src="banner.png"
alt="แบนเนอร์เว็บไซต์"
width="100%">

ขั้นตอนที่ 5 การเชื่อมลิงก์

ใช้คำสั่ง a href เพื่อเชื่อมโยง ไปยังหน้าเว็บไซต์ต่าง ๆ 

<a href="index1.html">หน้าแรก</a>

ขั้นตอนที่ 6 การตกแต่งด้วย CSS

ใช้ CSS กำหนดสีพื้นหลัง รูปแบบตัวอักษร และสีของเมนู เมื่อชี้เมาส์ 

nav a:hover {
    background: #00d9ff;
    color: #101735;
}

ขั้นตอนที่ 7 ทดสอบเว็บไซต์

เปิดไฟล์ index1.html ด้วย Google Chrome ทดลองคลิกเมนูทั้ง 3 หน้า และตรวจสอบว่ารูปภาพแสดงถูกต้อง

ขั้นตอนที่ 8 เผยแพร่เว็บไซต์

อัปโหลดไฟล์ HTML และรูปภาพไปยัง GitHub Repository จากนั้นใช้ GitHub Pages เพื่อเผยแพร่เว็บไซต์ โดยใช้ไฟล์ index.html เป็นหน้าเริ่มต้น

หน้าก่อนหน้า กลับหน้าแรก
